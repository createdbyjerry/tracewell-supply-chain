Design system

Technical documentation for the natural gas supply chain prototype.

Tech stack

Core
One HTML file: vanilla JavaScript, CSS custom properties, no build step
Graph engine
Hand-rolled SVG + DOM renderer with pan, zoom, drag, minimap and smooth-step edges (replaces React Flow 11)
UI components
Plain HTML elements styled to match the original Material UI 7 look

Color palette

Primary accent--twsc-primary
Background--twsc-bg
Surface--twsc-surface
Border--twsc-border

Typography

Montserrat ExtraBold
Headings and hero text
Montserrat Medium
UI labels and navigation
Montserrat Regular
Body copy and descriptions

Core components

Stage nodeA graph node with an icon, category and name. Circle nodes mark meters and tanks; blank nodes terminate labeled outflows.
Node inspectorSide panel with carbon intensity, methane and throughput data, plus the full upstream and downstream path of the selected stage.

Architecture principles

Real-time data

Graph state lives in plain JavaScript objects; only the edges touching a dragged node are recomputed, so large graphs stay responsive.

Traceability

Selecting a stage walks the graph in both directions and highlights its full lineage, so every product can be traced back to its source wells.

Responsive design

Panels collapse into sheets and overlays on narrow screens, and the palette adapts to light and dark system settings.
